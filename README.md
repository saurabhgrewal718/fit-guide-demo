# Fit Guide demo

Live demo: https://saurabhgrewal718.github.io/fit-guide-demo/

Fit Guide is a size advisor for clothing stores. Shoppers get their size from the store's own size chart, and the camera shows how each size sits on them. It runs in the shopper's browser and uploads nothing.

This repository only hosts the demo page and a compiled copy of the widget. The sample store and its size charts are made up.
